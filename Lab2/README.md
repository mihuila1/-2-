# Лабораторная работа 2. Объектно-ориентированное программирование

**Вариант 5.** Язык: C# (.NET 8), консольное приложение.

Решаемые задачи (по таблице распределения вариантов):

| Задание | Задача | Класс |
|---|---|---|
| 1 | 1.1 Точка | `Point` |
| 1 | 1.3 Имена | `Name` |
| 2 | 2.1 Прямая (Линия) | `Line` |
| 3 | 3.3 Города | `City`, `Route` |
| 4 | 4.8 Создаём города | `City`, `Route` |

Все классы находятся в одном проекте, каждый — в отдельном файле. В каждом классе есть свойства, конструкторы и метод `ToString()`.

- [.NET SDK 8](https://dotnet.microsoft.com/download) или новее. Если установлена другая версия, измените `TargetFramework` в `Lab2.csproj` (например, на `net9.0`).

```bash
cd Lab2
dotnet run
```

Или через Visual Studio / Rider: откройте `Lab2.csproj` и запустите проект.

## Ввод и ошибки

- Числа вводятся через `TryParse` в цикле: пока ввод некорректен, запрос повторяется.
- Для номера пункта меню проверяется диапазон, знаменатель дроби не может быть нулём.
- Для координат точки разделителем дробной части можно использовать точку или запятую.
- Деление на ноль и переполнение перехватываются: программа выводит сообщение об ошибке и возвращается в меню.

## Как устроены ключевые решения

- **Линия (2.1).** `Point` — ссылочный тип. Линия 3 создаётся как `new Line(line1.Start, line2.End)` и хранит ссылки на те же точки, поэтому следует за линиями 1 и 2. Чтобы изменить линию 1 и не затронуть линию 3, начало линии 1 заменяется новым объектом (`line1.Start = new Point(...)`), а не меняются координаты старого.
- **Города (3.3, 4.8).** Схема содержит циклы, поэтому города создаются по названию, а пути добавляются после (`City.Connect` — в обе стороны, `AddRoute` — в одну). Конструктор `City(string name, IEnumerable<Route> routes)` позволяет сразу создать город с набором путей.
- **Дроби (5.5).** Объекты неизменяемые, каждая операция возвращает новую дробь. Дробь хранится несократимой, знак — в числителе. Вычисления идут в `long`, при возврате в `int` используется `checked`.

## Допущения

- Пути на схеме городов (рисунок 2) приняты двусторонними, кроме `F → B` (только в одну сторону). Если на рисунке иначе, поправьте вызовы `City.Connect` и `AddRoute` в методе `DemoCityScheme` файла `Program.cs`.
- Стоимость пути должна быть положительным числом; путь из города в него самого не допускается.
